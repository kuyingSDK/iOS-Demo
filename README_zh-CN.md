# Kuying SDK iOS演示项目

## 介绍
这是一个iOS演示项目，用于展示Kuying SDK的集成和使用方法。

## 功能特性
- **激励视频广告**
- **插屏广告**
- **开屏广告**
- **横幅广告**
- **原生广告**

## 安装说明

### 环境要求
- iOS 13.0 或更高版本
- Xcode 16.0 或更高版本
- CocoaPods

### 安装步骤
1. 克隆此仓库：
   ```bash
   git clone https://github.com/kuyingSDK/iOS-Demo.git
   cd iOS-Demo
   ```

2. 安装依赖项：
   ```bash
   pod install
   ```
   或者
   ```bash
   pod install --repo-update
   ```

3. 打开工作空间：
   ```bash
   open SmartdigimktSDKDemo.xcworkspace
   ```

## 快速开始
1. 在Xcode中打开演示项目
2. 运行项目查看SDK集成示例
3. 查看源代码了解如何集成SDK
